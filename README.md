# Szőke Rebeka — Premium Media Kit 2026

Official media kit website source for Szőke Rebeka (Sz_Becca).

## Website

Once GitHub Pages is enabled, the website is expected to be available at:

https://jtdevzero.github.io/rebi-mediakit/

## Publishing with GitHub Pages

1. Open this repository's **Settings → Pages**.
2. Select **Deploy from a branch**.
3. Choose **main** and **/(root)**, then **Save**.
4. Wait for the Pages deployment to complete and check the public URL.

## Updating the media kit

Edit `index.html` in the repository and commit your changes. The page contains its own styles and scripts.

**Before sharing externally:** verify contact details, social media metrics, brand references, external image links, and mobile layout.
